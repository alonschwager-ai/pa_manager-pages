מדיניות פרטיות — מנהל הסמסטר

עדכון אחרון: 30 באוקטובר 2026

"מנהל הסמסטר" הוא כלי אישי שמשתמש בו אדם אחד בלבד, בעל הכלי, עם חשבון Google שלו.

אילו נתוני Google הכלי ניגש אליהם

  • זמינות ביומן הראשי (הרשאת calendar.freebusy): רק אילו שעות תפוסות ואילו פנויות. הכלי לא רואה כותרות, משתתפים או תוכן של אירועים.
  • יומן "לימודים" (הרשאת calendar.app.created): הכלי יוצר את היומן הזה, ויוצר, משנה ומוחק בו בלוקים של לימוד. הוא לא יכול לכתוב לאף יומן אחר.

איך הנתונים נשמרים ומשמשים

  • הנתונים משמשים רק לבניית תוכנית הלימוד של בעל הכלי ולשיבוצה ביומן.
  • הם נשמרים במסד נתונים פרטי במחשב או בשרת של בעל הכלי. הם לא נמכרים, לא משותפים ולא משמשים לפרסום.
  • כדי לנסח הודעות ולהעריך זמן עבודה, פרטי מטלות וזמינות עשויים להישלח ל-API של Anthropic (Claude). זה קורה רק לצורך פעולת הכלי.
  • השימוש במידע שמתקבל מ-Google APIs עומד ב-Google API Services User Data Policy, כולל דרישות ה-Limited Use.

מחיקה

אפשר לבטל את הגישה בכל רגע ב-myaccount.google.com/permissions. מחיקת מסד הנתונים המקומי מוחקת את כל המידע שהכלי שמר.

Privacy Policy — Semester Manager

Last updated: October 30, 2026

Semester Manager is a personal tool used by a single person, its owner, with their own Google account.

Google data the tool accesses

  • Primary calendar availability (calendar.freebusy): only which times are busy or free. The tool cannot see event titles, attendees or content.
  • The "לימודים" calendar (calendar.app.created): the tool creates this calendar and creates, changes and deletes study blocks in it. It cannot write to any other calendar.

How data is used and stored

  • Data is used only to build the owner's study plan and place it in the calendar.
  • It is stored in a private database on the owner's own computer or server. It is never sold, shared or used for advertising.
  • To write messages and estimate effort, assignment details and availability may be sent to the Anthropic (Claude) API, solely to operate the tool.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deletion

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local database removes everything the tool stored.
